# 注册用户账户详情

2026-09-13。用户确认注册目录已可访问，但点击业务入口后只看到“开户审批 / 尚未提交开户申请”。原因是目录没有用户详情路由，“开户审批”只显示开户状态，无法承担注册资料和账户查询。

## 修复范围

- 注册目录首列“查看详情”和邮箱链接进入独立用户账户详情，返回目录保留邮箱或页码。
- 展示登录邮箱、姓名、邮箱验证、登录身份、注册状态、用户状态、UTC 注册时间和本地用户 ID。没有开户申请也可查看基础资料。
- 展示原授权范围内的关联客户，以及账户名称、状态、ID、上级账户。支持客户切换和每页 20 条账户分页；审批保留独立入口。
- 缺客户关联、缺业务权限、暂无账户、读取失败及身份不存在分别展示。没有账户读取权限时不发起账户请求；服务端仍独立复核每次读取。
- 既有注册目录 GET 增加精确 userId UUID 查询，与 email 互斥、offset 必须为 0。复用既有 users:list 审计，不新增迁移。
- 不创建客户、修改授权、开通服务或生成余额，不调用真实金融写接口。

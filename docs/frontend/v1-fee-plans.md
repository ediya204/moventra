# V1 费率入口归并

2026-09-07 用户确认：移除独立用户组入口，费率统一在“费率管理”配置，保留底层继承关系。此决定更新早前 v1-personal-account.md 中保留商业用户组界面的范围。

- “客户与开户”只保留用户与开户、账户目录；移除侧栏和用户页面的独立用户组标签。
- “资金与财务 → 费率管理”统一管理费率方案与用户专属价格；工作台入口、筛选、表格、资料、审计操作标签改为“费率方案”。
- `/pricing` 为统一入口，`/pricing/plans` 为方案维护子页，`/pricing/plans/:id` 为方案配置详情，默认显示费率标签。
- 旧 `/user-groups/groups` 跳转 `/pricing`；旧详情保留 ID 和查询参数，replace 跳转到对应新详情。用户路径保持兼容。
- 复用 mg_groups、mg_users.group_id、mg_fees 和原 API；用户覆盖 → 方案配置 → 系统默认的费率计算顺序不变。未停用内部定价 API，未迁移数据或修改任何费率。
- 后台审批、操作员、财务权限及历史数据保持不变。费率方案没有邀请、协作或客户角色能力。

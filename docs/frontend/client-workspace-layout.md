## 布局约定

- 一级页面仅一个主标题，说明按页面任务编写。标题、分区导航、内容按顺序排列。
- 分区用可横向滚动的导航，取消页面中央的孤立大链接及重复操作条。2026-09-19按用户最新要求移除“人工出入金”独立导航入口，已有记录、查询接口和兼容详情链接保留。
- 数据列表保持宽幅；金额表单设置合理最大宽度；长 ID、地址可换行，表格只在容器内滚动。
- 首页显示钱包与近期记录；交易页仅保留卡片交易查询、筛选与导出，移除近期资金交易区，资金历史通过链接进入。
- 设置集中账户、安全与开户状态；消息与帮助用明确能力说明和可用路径，不渲染重复通用占位卡。
- 加载、空结果、服务失败与功能未开放分别表达；二三级页面仍能通过 URL 恢复并返回。

# 资金流与运营概览

2026-09-07。页面实现复用项目 MUI 主题、Card/CardHeader、Select、Table、Chip、LinearProgress 和 ApexCharts，遵循 Minimals 组件体系；未复制外部模板源码或增加图表依赖。

正式入口 `/workbench`：运营身份及 MFA 验证后，从 `/session` 进入概览；身份设置保留在 `/session?security=1`。后端仍逐客户检查 `transactions:read`，前端路由不承担数据授权。

功能包括最近 7/14/30 个香港自然日的流入、流出、净流量、交易笔数，每日资金流、交易活跃度、状态分布、需关注交易，以及每日精确明细与 CSV 导出。未知金额显示 `—`；无来源日期保留空白。状态比例不称为授权成功率，收支不称为收入、利润或余额。

## 数据源与更新

- 正式环境：读取 Go 中已授权的 USD 交易投影。完成状态不证明渠道结算；卡片、商户、来源同步时间不可用时明确显示未接入。详细口径见 [运营接口](../../services/api/docs/operations-overview.md)。
- 本地 DEV：复用旧服务已保存的 Slash 只读投影，可显示来源商户排行、选定卡状态及最近成功读取时间。旧 Node/Python、真实数据、凭据和同步服务不随前端发布。
- 首次打开、切换周期或点击刷新重新计算当前投影。刷新图表不触发渠道同步；旧环境保持手动同步。查询时间与渠道同步时间分别展示。
- 接口失败清空旧统计并提供重试；周期切换丢弃过期响应。CSV 金额按 USD 分以整数字符串导出，不转换为浮点金额。

## 验证与交付边界

`tests/frontend/operations-overview.test.mjs` 覆盖精确大金额、未知值、CSV 防公式注入、接口白名单、会话切换、失败/重试、空数据、周期切换及运营 MFA 页面准入。`deploy/cloudflare/gateway.test.mjs` 覆盖 admin-only、Bearer、方法限制及查询转发。Go 测试和隔离 PostgreSQL 场景见接口文档。

本地页面可用和自动化通过不等于正式渠道已接入。线上需现有运营授权和 MFA，数据仅来自该身份获准读取的交易投影；本次不进行迁移、导入本地真实数据或真实金融写操作。部署结果另记于发布记录。

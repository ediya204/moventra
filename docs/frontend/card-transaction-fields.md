# 卡片与交易 Tab / 列表字段规范

2026-09-07。本次为显示与交互规范，不变更数据库、来源状态、金额存储或服务端查询契约。

## Tab

- 数据来源：Slash 数据 / Demo 数据。两者继续隔离；默认来源及查询参数值不变。
- Demo 卡片：卡片列表 / 操作审批。
- Demo 交易：交易列表 / 跨币种报表。报表返回交易列表明确携带 source=demo。

## 展示口径

- 缺失值为 —；金额零保留为 0.00；无效金额/时间明确提示，不崩溃、不伪装成功。金额右对齐、等宽数字。
- 来源状态带中文与原值，未知枚举显示“未知状态”及原值。卡片渠道暂停不等于内部风控冻结；Demo 原有业务状态及后端中文映射保留。
- 平台卡片 ID 尾段标注 ID，不冒充卡号后四位。只展示已有脱敏后四位。
- [Slash Transaction](https://docs.slash.com/api-reference/schema-transaction)：amountCents 为 USD 来源分；pending 金额不标为最终清算金额。date 在 posted 时表示入账日期，在 pending/failed 时表示创建日期，因此来源日期与入账时间分列。两层状态分别保留。
- [Slash Card](https://docs.slash.com/api-reference/schema-card)：来源渠道状态独立展示，不替代内部冻结/审批状态。
- 原币金额只格式化已核验的 USD/CNY/AED 两位来源单位；其他来源币种保留原整数并注明“来源最小单位”，不按 ISO 精度猜测。原币对象缺失不从账户金额或当前汇率补造。
- Demo 可用资金是内部卡分户账本，不能当作渠道限额或渠道账户余额。
- 查询、分页和既有交易排序仍由服务端执行；卡管理接口尚未提供排序，禁用其原本无效的排序入口。操作列置后。

## 卡片默认列调整

“状态”及筛选仍读取渠道 cardStatus，不替换为内部冻结状态。“用户”只读取明确的 internal.customerName/customerId；当前真实 Slash 投影未建立映射，显示“未关联用户”，不得将卡片名称、持卡人姓名或渠道账户名称作为内部用户。新增“渠道”列，当前接口为 Slash；可读 platform 的其他渠道名称（如 Wasabi），不表示该渠道已接入。同步状态仍为独立字段，移入可选列。两套源码同步调整，未改资金、权限或用户归属数据。

## 2026-09-18：关联卡片后四位修复

差异：交易投影未保存 cardLast4 时，原查询没有补取关联卡片 last4，列表及详情因而显示未知。

查询兼容方案：客户交易保留已提供的 cardLast4；缺失时仅从相同 connection、revision、cardId、accountId、virtualAccountId 的卡片记录补取 cardLast4/last4。仍在原授权范围内分页、计数和审计，尾号关键词使用同一补取表达式。仅返回四位展示字段，不修改持久化数据和金额状态，不使用卡片 ID 后四位冒充卡尾号。

列表与抽屉展示 `•••• 2047`；真实缺失仍为“尾号未知”。本地前端7项测试及生产构建通过；临时数据库回归覆盖客户固定快照和项目钱包的列表、详情、尾号筛选、跨版本隔离和既有权限拒绝。本次未验证线上真实数据、未部署API或客户端、未执行生产迁移。

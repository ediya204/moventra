# 本地 Demo 快照

## 两种运行模式

| 模式 | 数据来源 | 是否修改线上 | 是否本地保存业务数据 |
| --- | --- | --- | --- |
| 线上只读 | 现有 `/admin-api` 查询接口 | 否 | 否 |
| 本地 Demo | 内存生成数据或脱敏 `snapshot.json` | 否 | 可选，仅保存脱敏快照 |

产品验证阶段推荐先使用内存 Demo。它包含完整关系和六个月交易，无需生产凭据。

## 导入线上只读快照

导入器只调用现有查询 API。访问令牌通过进程环境传入，不写入命令脚本、项目文件或快照。

```bash
Moventra_SOURCE_BASE="https://your-readonly-api.example.com" \
Moventra_READ_TOKEN="在当前终端临时注入" \
Moventra_SNAPSHOT_SALT="由团队保管的随机盐" \
pnpm demo:import
```

导入范围：主账户、子账户、卡片、最近约 183 天交易、账户风险和渠道余额。线上接口若不支持时间参数，仍以接口实际返回范围为准，导入日志不会声称已获得完整六个月。

自动处理：

- 邮箱替换为 `example.invalid` 假地址；
- 用户、卡片和交易标识使用带盐哈希重映射，并保留对象关系；
- 完整卡号仅保留尾号；地址和电话号码遮罩；备注内容替换；
- 卡安全码和 OTP 永不保存，OTP 列表固定为空；
- 文件权限设置为仅当前用户可读写，并通过 `.gitignore` 排除。

生成后运行：

```bash
pnpm demo
```

本地 API 检测到 `demo-server/snapshot.json` 后会优先加载。删除该文件后会恢复内存生成的 Demo 数据。

## 数据边界

快照适用于 UX、导航、筛选、图表和多级钻取验证，不适用于财务对账、风险结论、生产运营或真实性证明。页面会明确区分“服务端汇总”和“当前加载样本”。

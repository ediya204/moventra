# 卡 BIN 详情状态管理（2026-09-07）

原有状态选择位于“开卡规则”，窄屏在长表单下方，容易被遗漏。现在移至维护详情首屏的独立状态区域，展示当前状态、待保存变更、状态影响及保存按钮；采用现有MUI组件，列表同步区分草稿、上架、暂停、归档颜色。

继续使用现有 GET/POST management/bins/:id 与 revision 校验，没有新增重复状态或伪接口。状态和其他产品配置一并保存，服务端确认后刷新。已归档产品不能恢复；新增归档影响提示；保存中禁止重复提交。本站产品状态不修改 Slash 卡片状态。

客户端既有规则：草稿/归档不展示，已上架在渠道和数量条件允许时可开卡，暂停仍显示但不可开卡，已开卡不受产品暂停影响。

验证：card-bins、channels、verified-catalog 合计13项测试通过；旧运行目录和规范仓库后台构建通过。浏览器确认详情顶部状态区域及四种选项，无实际保存或改动8个Slash产品状态。只更新本地页面，未部署。

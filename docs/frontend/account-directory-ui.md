# 账户目录与详情整理

2026-09-07，本地只读页面调整，无数据库迁移、账户归属或资金变更。

- `/customers` 默认列：账户名称、邮件地址、状态、余额、操作。账户类型、渠道、平台账户 ID 与同步信息在详情中查看。
- 账户状态使用 MUI Chip；未知状态保留原值，缺失信息不当作正常或零。
- 操作列位于最后；整行单击进入详情，链接和按钮保留各自操作。查询按钮不再换行。
- `/customers/:id`：账户概览、关联卡片、关联交易、数据来源四个标签；URL 保留当前标签。返回列表保留原关键词和分页，返回地址限定本地账户列表。
- 关联记录复用原查询接口，强制附加当前账户 ID，查询、分页、排序与 CSV 导出均走后端；切换标签清除前一列表的筛选。
- 账户概览保留所属用户内部映射、渠道、余额与虚拟账户。available / posted 按币种、余额类型分别展示，不求和；余额说明明确为 Demo。
- 版本、同步、映射假设与内部余额变化记录收拢到数据来源；移除概览的装饰性快照曲线，底层历史记录保留。
- 来源口径复核：[Slash Account Balance](https://docs.slash.com/api-reference/account-balance-get)。余额类型与账户类型不混用，未知币种不默认 USD。

实现同步在旧本地运行目录与 Moventra `packages/shared/src/slash`，不向共享包引入对应用目录的反向依赖。

验证：旧项目构建、16 项 Slash 数据测试；Moventra 两端类型检查、构建及 29 项测试通过。浏览器验证 S01 账户的关键词搜索、整行点击、四个详情标签、本账户卡片与交易各一条、余额 900.00 USD / 900.00 USD、三个余额变化步骤，以及返回时筛选保留。未执行渠道写接口、部署或真实业务验收。

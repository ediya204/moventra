更新日期：2026-09-06。状态：DESIGN 测试要求，不是本次测试通过报告。

已有 [S01–S20 Demo 场景](../frontend/slash-demo-scenarios.md) 和 [既有验证记录](../frontend/slash-demo.md) 保留。下列 F 编号用于新规范，不修改原种子或假设。

## 1. 测试分层与数据隔离

- 官方 Schema 契约测试：只验证真实字段与类型，不把内部扩展放进 source；未知枚举另作为故障注入，不冒充合规样例。
- 适配器测试：金额、状态、时区、原始缺省和能力映射，基于固定官方摘录并记录 URL/核验日期/摘要。
- 领域测试：资金不变量、关联和状态组合；未获渠道确认的路径标记 `internal_assumption`。
- 查询/UI 测试：前后端金额一致、权限、分页与总计、未知值和失败显示。
- 同步/数据库测试：重复、乱序、重启、并发、回填、事务、审计与历史纠正。
- 真实渠道测试：单独授权、脱敏证据；本地模拟签名、版本或余额公式不替代实证。

Demo 必须包含 namespace、seed、scenarioId、assumptionLevel、sourceEvidence、expectedResults。重复导入不重复影响金额；禁止使用真实凭据、PAN/CVV/OTP。数据清理仅限明确命名空间；不得清空业务库。

## 3. 外币场景

### F17：CNY 消费、USD 记账及部分退款

假设原消费 CNY720、授权 USD100；最终消费入账 USD101、独立费用 USD1.01；退款原币 CNY360、实际 USD49.80。

- 入账流水最小单位：-10100、-101、+4980；合计 -5221，即账户净变化 -52.21 USD。
- 已确认该订单净支出52.21 USD；原币净消费360 CNY。
- 费用注释即使重复出现仍只计一次费用。
- 退款不按授权/原扣款汇率重算；全部输入属于内部假设，不证明 Slash 实际收费政策。

### F18：AED 与混合币种

假设 AED367.25 对应独立来源入账 USD100；费用未知。该已知消费影响为 -100 USD，费用状态为未知，不能声称含费最终总额已确定。

与 F17 汇总时：USD 已知入账净变化为 -152.21；原币分组分别 CNY360 和 AED367.25，不把两者相加。若接口计算的是含全部费用的完整支出指标，必须因 F18 未知费用标记不完整。

### F19：精度及来源编码

第二模拟渠道配置合法 scale=0 与 scale=3 资产样例，验证格式化/汇总不固定两位；测试大于 JS 安全整数范围、负值、零、边界溢出、非法指数和小数最小单位。该测试不声明 Slash 已支持对应货币编码。

## 5. 安全、接口与性能验收

- F33：伪造签名、改变原始请求体、错误连接/主体 → 拒绝处理；真实验签需单独认证测试，不以 Demo RSA 夹具代替。
- F34：MLE 解密失败、缺少强制加密响应、错误密钥 → 安全失败；不降级明文，不输出敏感日志。
- F35：跨客户详情/关联/汇总/导出/缓存读取、无运营 MFA、新权限缺失 → 服务端拒绝。
- F36：查询端点被利用调用渠道写接口 → 服务端白名单拒绝，不能触发 deferred action。
- F37：分页、半开时间边界、跨月/夏令时、非法筛选、游标与筛选不匹配 → 无越权或静默错统计；当前页不冒充总计。
- F38：大样本回填、实时同步并行、慢源、429、超时、异步导出 → 有界资源与可恢复队列。规模/阈值待实测明确，不能仅跑小样本就宣称满足大数据量。

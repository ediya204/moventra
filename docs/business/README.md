# 全站业务逻辑总览

更新日期：2026-09-18。按本地 main `89ca9c3`、当前工作区和已有发布记录整理；当前能力、未提交增量和验证限制统一见[状态摘要](../current-state.md)。本文描述职责和流程，不把代码、历史测试、生产发布视为同一结论。原详细调查保留为[历史快照](../releases/2026-09-07-business-overview-snapshot.md)。

## 系统与数据职责

| 部分 | 职责 | 边界 |
| --- | --- | --- |
| 官网与客户端 | 咨询邮件、客户登录、开户申请、个人查询、授权卡片与线上测试资金 | 企业团队协作未开放；消息/工单等导航不代表办理服务可用 |
| 运营后台 | 管理员登录/MFA、开户审核、用户/账户目录、渠道查询、测试资金审核和 BIN 目录 | 管理角色不自动拥有全部客户/渠道权限；目录管理不等于真实开卡 |
| Go/PostgreSQL | 身份授权、业务数据、查询投影、测试订单、配置与审计 | 客户投影、渠道来源、测试资金及 shadow 模块分开 |
| 本地业务服务 | 隔离 Demo、用户/费率/BIN/卡操作/资金原型与采集工具 | 源码已恢复，私有数据未迁入；不能直接代理成生产资金后端 |
| Slash | 授权只读来源、手动投影导入、普通通知及来源观察 | 普通通知不做支付授权，不自动更新前端投影或记账 |
| Blnk | 本地 shadow 钱包、逐卡/在途分户、幂等任务与核对 | 生产账本权威未切换；不能当成真实卡余额或上游对账证明 |

主链为浏览器 → 同域网关 → Go 授权 → 数据与审计。Webhook 是另一条验签 → 收件箱 → GET → 来源观察链。两条链没有证据时不能宣称自动联通。

## 身份、所有权与资金归属

- Firebase UID 证明登录身份；users.role 区分 customer/admin。个人主体、业务开通、资源授权和运营 MFA 分别判定。
- staff_grants 规定逐客户权限；channel_read_grants 规定来源连接权限；测试资金、目录、ledger 使用对应独立授权，不相互继承。
- 项目共用上游钱包与内部客户分户分开；卡片按显式 cardId 分配。当前绑定不是历史资金所有权证明，卡名/尾号/cardholder 不能作为归属依据。
- 后台显示客户身份还需 accounts:read；有渠道权限不能自动读所有客户身份。前后台 DTO 按各自用途裁剪。
- 新来源记录、重复导入或用户注册不能自动扩张业务授权，也不自动复制资金余额。

## 按流程阅读

| 业务任务 | 路径及结果 | 专题与验收边界 |
| --- | --- | --- |
| 官网咨询 | 表单 → 同域邮件受理 → 结果反馈 | [邮件发布记录](../releases/2026-09-07-website-contact.md)；受理不保证最终送达 |
| 登录与开户 | 本站登录 → Go 身份 → 客户申请 → 运营处理 → 服务状态/资格 | [两角色登录](two-role-login.md)、[开户资格](../frontend/onboarding-feature-access.md)；激活不自动产生资金 |
| 账户和交易查询 | 入口 → 列表/筛选 → 详情/关联 → 返回 | [现行路由](routes-and-api.md)；基础投影与渠道投影口径不同 |
| 卡片归属与查询 | 固定来源/钱包范围 → 明确分配 → 客户及后台查询 | [项目钱包](project-wallet.md)、[归属显示](card-owner-display.md)；不是上游卡控制 |
| 模拟资金 | 客户测试申请 → 服务端订单 → 运营审核/模拟处理 → 客户查询 | [线上测试资金](online-test-funds.md)；与真实付款及 Blnk 隔离 |
| BIN 产品管理 | 来源目录导入 → 供应商/产品/价格 → 审计 | [BIN 目录](bin-catalog-sync-2026-09-18.md)；真实发卡保持关闭 |
| 卡详情扩展 | 列表 → 单卡详情 → 交易/资金记录/操作记录 | [规划](card-center-detail-plan-2026-09-18.md)；四标签和敏感展示仍为 DESIGN |
| 上游通知 | 验签 → 持久化 → 异步 GET → 白名单观察 | [上线记录](../../deploy/slash-webhook-online-2026-09-18.md)；不代表全量同步 |
| 账本与对账 | 内部分户 → 业务逐笔 → 可比上游资金池 → 差异处理 | [领域规则](../domain/transactions-and-funds.md)、[对账设计](../domain/reconciliation-v1-plan.md)；缺期初/覆盖不能显示对平 |

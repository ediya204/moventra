# 工程任务与交接模板

本模板补充[业务闭环标准](../business/delivery-standard.md)，不替代其中的完整 FLOW 流程卡。新任务复制到对应业务/集成专题中填写；简单文字修正无需创建任务文档。

## 目标与基线

- FLOW 编号、目标、起点和终点：待填写。
- 日期、工作目录、分支/提交、相关未提交差异：待填写。
- 已授权范围、环境及不在本批内的事项：待填写。
- 现有实现与需求差异、兼容方案：待填写。
- 采用的规则和专题：使用相对链接引用，不复制整篇。

## 流程与决策

按业务闭环标准填写页面关系、业务身份、数据权威、接口链、状态及动作、跨端变化、权限、异常恢复与验收。

| 待填写 | 待核实 | 待分配 | 待填写 | 未定 |
